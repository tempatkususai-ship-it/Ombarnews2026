Alur Publikasi (Hosting Statis)

  1. Edit artikel / pengaturan di dashboard ini — perubahan langsung tampil di situs pada browser yang sama.
  2. Klik Export di menu Export / Import untuk mengunduh ombar-data.json.
  3. Commit & push file tersebut ke repo GitHub Anda (atau timpa data-store.js), lalu deploy ulang.
  4. Deploy ke GitHub Pages atau Cloudflare Pages — lihat DEPLOY.md di dalam ZIP.

    Settings

    Identitas dan teks global situs.

    Security

    Ubah kredensial login admin.

    Catatan: Kredensial disimpan di localStorage browser admin. Ini bukan pengganti autentikasi server. Siapa pun yang membuka dashboard di browser yang sama bisa login setelah kredensial disetel. Untuk keamanan produksi, gunakan auth backend.

    Export / Import Data

    Publikasikan perubahan ke hosting statis Anda.

    Export & Publish

    Unduh seluruh konten (artikel, kategori, pengaturan, breaking) sebagai ombar-data.json.

    Source Code (ZIP)

    Unduh seluruh source code website (HTML + CSS + JS + admin + gambar) sebagai satu file ombar-news.zip — siap di-upload ke GitHub & Cloudflare Pages.

    Download ombar-news.zip Baca DEPLOY.md

    Ekstrak ZIP → index.html ada di root → push ke repo GitHub → aktifkan Pages, atau connect repo ke Cloudflare Pages. Lihat DEPLOY.md untuk langkah lengkap.

    Import

    Muat ulang data dari file ombar-data.json yang sebelumnya diexport.

    Reset

    Hapus semua perubahan dan kembalikan ke data bawaan.
