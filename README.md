# OMBAR NEWS — Raja Ampat & Beyond

Portal berita digital profesional bertema Raja Ampat, Papua Barat Daya, Papua,
nasional, dan internasional. Dibangun dengan **HTML5 + CSS3 + JavaScript vanilla**
(tanpa framework), siap untuk hosting statis (GitHub Pages / Cloudflare Pages).

## Mulai Cepat

Buka `index.html` di browser — tidak perlu server.

Untuk admin: buka `admin/login.html` → login `admin` / `ombar2026`.
